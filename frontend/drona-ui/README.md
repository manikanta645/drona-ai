# 🪔 DRONA – Ancient Wisdom AI

## 📚 What is DRONA?

**DRONA** is an advanced AI learning platform inspired by **Dronacharya** from the Mahābhārata. It provides personalized training in ancient Indian wisdom, martial arts philosophy, vedic knowledge, and spiritual disciplines through interactive modes and guided learning paths.

The system features a **Guru-Shishya (Teacher-Student)** dynamic where DRONA responds as an ancient, wise teacher who understands your questions and guides your learning journey.

---

## 🎯 Key Features

- **7 Training Modes** - Specialized training with distinct UIs
- **6 Vidya (Knowledge) Submodes** - Deep learning in specific disciplines:
  - 🧘 Dhyana Vidya (Meditation)
  - ⚔️ Khadga Vidya (Sword Mastery)
  - 🏹 Dhanur Vidya (Archery)
  - ⚖️ Dharma Vidya (Righteousness & Philosophy)
  - ⚔️🛡️ Yudha Vidya (War Strategy)
  - 📚 Shastra Vidya (Ancient Texts & Sacred Knowledge)
- **Multilingual Support** - Learn in English, Hindi, Sanskrit, and other Indian languages
- **Memory Persistence** - DRONA remembers your learning history and progress
- **Voice Input/Output** - Speak to the guru and hear responses
- **Real-Time Learning** - AI learns new topics automatically
- **Professional Dronacharya Avatar** - Display of the actual guru image in all modes
- **Camera Integration** - Real-time posture tracking in meditation and training modes

## ✅ The Universal Cross-Mode Redirection Rule

### **What Is It?**
A system that intelligently redirects you when you ask about topics outside the current mode's focus.

### **How It Works**
When you ask a question that belongs to a different mode, DRONA doesn't reject you. Instead, he uses the **Guru-Style Redirection**:

**Template:**
```
"Shishya, first understand the knowledge of this mode.
When you are ready, the deeper knowledge of [other mode name] awaits you there.
But in this mode, only [mode's function] is taught."
```

### **Example**
If you're in **Dhanur Vidya (Archery)** and ask "Teach me sword techniques":
```
"Shishya, first understand the way of the bow here.
When you are ready for other arts, their doors will open.
But in this mode, only Khadga Vidya is taught."
```

Then DRONA might suggest switching to Khadga Vidya for deeper sword learning.

### **Why This Matters**
- **Respectful Guidance** - Like a real guru directing your learning path
- **Focused Learning** - Prevents scattered knowledge
- **Progressive Training** - Master one discipline before moving to the next
- **Holistic Understanding** - Each mode builds on others

## 🚀 How to Run This Project

### **Prerequisites**
- **Node.js** (v14 or higher) - [Download](https://nodejs.org/)
- **npm** (comes with Node.js)
- **Backend running** - DRONA backend API must be running on `http://127.0.0.1:8000`

### **Step 1: Install Dependencies**
```bash
npm install
```

### **Step 2: Start Development Server**
```bash
npm start
```

The app will open at `http://localhost:3000`

### **Step 3: Interact with DRONA**
- Click on "Start Learning" to initialize
- Choose a training mode from the sidebar
- Ask questions or explore different vidyas

## ⚙️ Backend Configuration

### **Changing the Ollama Model**

**File:** `backend/main_ollama.py`

**Find this line:**
```python
OLLAMA_MODEL = "gpt-oss:120b-cloud"
```

**Change to any available model:**
```python
OLLAMA_MODEL = "mistral"  # or "llama2", "neural-chat", etc.
```

**List available models:**
```bash
ollama list
```

### **Changing the Ollama Path**

**File:** `backend/main_ollama.py`

**Find this function:**
```python
def get_ollama_executable():
    ollama_paths = [
        "ollama",
        "ollama.exe",
        os.path.expanduser(r"~\.cargo\bin\ollama.exe"),
        r"C:\Program Files\Ollama\ollama.exe",
        r"C:\Program Files (x86)\Ollama\ollama.exe",
        os.path.expanduser(r"~\AppData\Local\Programs\Ollama\ollama.exe"),
    ]
```

**Add your custom path:**
```python
r"C:\Your\Custom\Path\ollama.exe"  # Windows
```

### **Setting Ollama Server Address**

If Ollama is running on a different machine, update:

**File:** `backend/main_ollama.py` - `ask_ollama()` function

**Current (local):**
```bash
ollama run gpt-oss:120b-cloud "prompt"
```

**For remote server:**
```bash
ollama run gpt-oss:120b-cloud "prompt" --url http://remote-ip:11434
```

## 📋 Necessary Changes for Deployment

### **1. Backend Configuration**
- [ ] Update CORS settings in `backend/main_ollama.py` for your domain
- [ ] Update model and ollama path
- [ ] Ensure Ollama service is running
- [ ] Test API connectivity: `http://[backend-ip]:8000/docs`

### **2. Frontend Configuration**
- [ ] Update `API_URL` in `src/App.js`
- [ ] Create `.env` file with correct API endpoint
- [ ] Test voice input permissions (browser may request microphone access)
- [ ] Verify all dependencies: `npm install`

### **3. Network Setup**
- [ ] Both frontend and backend must be on the same network or internet-accessible
- [ ] Ensure firewall allows ports 3000 (frontend) and 8000 (backend)
- [ ] If using HTTPS, update API URLs accordingly

### **4. Memory & Storage**
- [ ] Check disk space for Ollama models (can be 5-20GB+)
- [ ] Memory file: `backend/data/memory.json` must be writable
- [ ] ChromaDB database: `backend/data/chroma_db/` must be accessible

## 🛠️ Troubleshooting

### **"Cannot connect to backend"**
- Ensure backend is running: `uvicorn backend.main_ollama:app --reload`
- Check API_URL in `src/App.js` is correct
- Verify firewall allows port 8000

### **"Ollama not found"**
- Ensure Ollama is installed: [Download Ollama](https://ollama.ai)
- Check ollama paths in `backend/main_ollama.py`
- Run `ollama serve` in another terminal

### **Model not working**
- List available models: `ollama list`
- Pull a model: `ollama pull mistral`
- Ensure model name matches in code

### **Slow responses**
- Check model size (smaller = faster)
- Ensure sufficient system RAM
- Check internet (if using cloud models)
